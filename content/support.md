## Contact support

Email {{< contact >}} with **SHADO support** in the subject. Include the app or browser version, the device you're using, the approximate time of the issue and the steps that led to it.

Remove credentials and private content from screenshots or logs. Do not send your password, API keys or pairing tokens. Support availability and response times are not covered by a service-level agreement unless separately agreed.

## Open the dashboard

The Dashboard button opens the connected SHADO dashboard. Access requires authorization; visiting this website does not create a dashboard account.

{{< dashboard >}}

For an organization-managed installation, use the dashboard address supplied by your administrator instead of assuming this demonstration deployment is your organization's server.

## Connect the mobile app

1. Obtain access to a running SHADO server from its operator.
2. Follow the app's connection or pairing flow using the server details supplied to you.
3. Authenticate using a method enabled for that deployment.
4. Confirm that the server is reachable from your phone's network.

The companion app connects to a server; it does not turn the phone into the SHADO host. Store download links on this website are currently placeholders.

## Troubleshoot a connection

**The dashboard will not open:** check the server address, network or VPN access and whether the server is available. Contact your deployment administrator if it is an internal system.

**Sign-in fails:** confirm that you are using the right deployment and an enabled sign-in method. Request access from the operator rather than sharing another person's credentials.

**A model is slow or unavailable:** ask the operator to check whether the model is installed, loaded and supported by the available compute. A first request may take longer while a local model loads.

**A tool or integration is missing:** check the selected preset and whether the capability has been installed, configured and enabled for it.

**Speech is unavailable:** check microphone permission and the configured speech engines. Server-side speech components must be available for features that depend on them.

## Manage your data

The operator of your SHADO server controls its stored conversations, files, integration settings and backups. Contact that operator for deployment-specific access, correction, retention or deletion requests.

Signing out of a client or uninstalling an app is not a request to erase server-side information. Ask the operator to explain which copies, logs and backups are affected by deletion.

For information you emailed directly to the creator, send your request to {{< contact >}}. See the [Privacy Policy](/privacy/) for details.

## Report a security concern

Email {{< contact >}} with **SHADO security** in the subject and a minimal description of the issue. Avoid including real credentials or private user data. Please do not post sensitive findings in a public issue or test systems you are not authorized to access.
